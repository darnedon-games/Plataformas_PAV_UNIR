# Plataformas_PAV_UNIR

Repositorio para la actividad Juego de Plataformas para la asignatura Programación y Arquitectura de Videojuegos

## Contenidos Actividad
Tema 3. Animación y colisiones
Tema 4. Cámara, UI y sistema de guardado

## Descripción prototipo
Sortea todos los obstáculos y alcanza la cima para poder escapar del planeta Marte en "MARS ESCAPE".

## Cómo se juega
Desplazamiento lateral: teclas A y D
Salto: barra de espacio
Dash: tecla CTRL IZQ.
Agacharse: SHIFT
Disparar: click izquierdo del ratón
